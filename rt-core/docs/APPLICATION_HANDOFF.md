## Ordering and authority

The current local grant lasts 500 ms and its Python SDK renews every 100 ms;
these are current implementation values, not a substitute for the target clock
and latency contracts. Preserve independent authority expiry and jog input expiry.
The native 1.5 cycle independently enforces the same application grant through
generated direct request/observation slots; connection heartbeats do not grant
motion. Native expiry or revocation cannot be repaired by renewing the old
identity. The current Go adapter obtains a new admitted grant after Stop before
returning replacement authority. Source-fixed jog ingress remains separate work.
Stop/release/restart revoke every lane. New motion needs fresh Enable/Arm and
observed group readiness; renewal never refreshes a stale jog input.

Keep the motion server's established leader/executor ordering: snapshot leader
state before taking the executor mutex, serialize tick versus abort output, and
prevent an old tick from emitting ON after revoke returns. Join the ingest accept
thread before closing/resetting its listener descriptor. Migration tests must
retain these contracts while replacing the motion transport.

Current pair ID/revision/configuration SHA are explicit deployment inputs, and
the local socket group is trusted. The target must verify the effective native
configuration and provision that group; neither an echoed SHA nor a submitted
controller name proves remote authority.

## Plan and process continuity

Use explicit axis mapping and real planner fixtures. Resolve the format's 1e-3
boundary tolerance versus native adapter's 1e-12 stationary continuity through a
versioned producer/validation policy. Changed samples require new digests. Do not
invent connecting motion, drop dwell or silently omit process markers.

Torch intent, a NATS publication and physical output acknowledgement are distinct.
Tie marker validity to execution/generation and invalidate pending ON on Stop,
expiry or restart. Define what happens when feedback or marker delivery is late.
Any Pause/Resume exposed by an application needs a qualified halt and validated
continuation, not replay of a cancelled trajectory.

The SDK tool is an intermediate integration aid. Full handoff requires the actual
consumers above and the physical gates in [MIGRATION.md](MIGRATION.md).
